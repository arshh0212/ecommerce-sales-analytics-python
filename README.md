# E-Commerce Sales Analytics Using Python

## Project Overview
An exploratory data analysis project investigating e-commerce sales,
revenue patterns, customer behavior, and business performance.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Kaggle Notebooks

## Key Analyses
- Revenue by Product Category
- Monthly Revenue Trends
- Regional Sales Performance
- Payment Method Analysis
- Customer Ratings and Delivery Time
- Discount Analysis
- Customer Behavior
- Business KPIs
- Data Quality Checks

## Project Notebook
[View the Kaggle Notebook](https://www.kaggle.com/code/arshanalytica/e-commerce-sales-analytics-revenue-customers-i)

## Dataset
The dataset used in this project is available on Kaggle.

[View E-Commerce Sales Analytics Dataset](https://www.kaggle.com/datasets/arshanalytica/e-commerce-sales-analytics-dataset)

## Objective
To use Python-based data analysis and visualization to identify
business patterns and develop data-driven recommendations.
